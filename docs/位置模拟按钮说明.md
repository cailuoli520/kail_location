# 位置模拟页面「按钮说明」功能

> 入口：位置模拟页面（`LocationSimulationActivity`）顶栏右上角的 **`?`** 按钮
> 实现文件：`app/src/main/java/com/kail/location/views/locationsimulation/LocationSimulationScreen.kt`
> 文案文件：`app/src/main/res/values*/strings.xml`（`loc_sim_help`、`help_*`）

## 1. 功能效果

点击顶栏右上角的 `?` 按钮后：

- 整个屏幕蒙上一层**半透明灰色遮罩**（不影响看清下面的按钮）。
- **每个按钮的右上角出现一个橙色圆形数字角标**（1、2、3…），明确指向该按钮。
- **底部弹出「按钮说明」图例面板**，按编号逐条列出每个按钮的作用，内容很长时可上下滑动。

退出方式：点击屏幕任意位置（含图例面板）即可关闭，同时数字角标与图例一起消失。

## 2. 覆盖的按钮与说明

| 编号 | 按钮 | 说明 |
| --- | --- | --- |
| 1 | 左上角“☰”菜单按钮 | 打开功能菜单，跳转到其他模块 |
| 2 | 卡片右上角“+”按钮 | 添加 / 更换模拟位置 |
| 3 | 卡片标题区域 | 点击此区域折叠 / 展开卡片 |
| 4 | “启动/停止模拟”按钮 | 启动 / 停止位置模拟 |
| 5 | 卡片内“上/下箭头”按钮 | 折叠 / 展开卡片 |
| 6 | “摇杆”开关 | 摇杆开关，开启后显示摇杆浮窗 |
| 7 | 卡片内“齿轮”按钮 | 速/频设置（步频模拟参数） |
| 8 | “常用 / 历史” Tab | 切换常用 / 历史位置列表 |
| 9 | 搜索按钮 | 搜索历史记录 |
| 10 | 历史卡片“星标”图标 | 收藏 / 取消收藏此位置 |
| 11 | 历史卡片“铅笔”图标 | 重命名此位置 |
| 12 | 历史卡片“垃圾桶”图标 | 删除此位置 |

> 卡片当前处于折叠状态时，4~7 号按钮本身不显示（角标也就不出现），其余按钮的说明正常展示。

## 3. 图例面板交互

- **可拖动**：面板顶部有一条白色小拖拽条，按住即可将整个面板拖到屏幕任意位置，避免遮挡想看的按钮。
- **可滚动**：面板内列表超出高度时上下滑动浏览。
- **点击关闭**：点击面板任意位置或遮罩任意位置均可关闭。

## 4. 支持的界面语言

按钮说明文案随系统语言自动切换，当前已翻译：

| 语言 | 资源目录 |
| --- | --- |
| 简体中文 | `values/strings.xml`（默认） |
| 英文 | `values-en/strings.xml` |
| 日文 | `values-ja/strings.xml` |
| 繁体中文（香港） | `values-zh-rHK/strings.xml` |
| 繁体中文（台湾） | `values-zh-rTW/strings.xml` |

## 5. 附带说明

- 数字角标只在帮助模式下显示，正常使用时按钮上无角标。
- 已去除原先基于坐标追踪的悬浮气泡方案，改为角标直接叠加在按钮自身布局上，位置天然准确，无需对准。
